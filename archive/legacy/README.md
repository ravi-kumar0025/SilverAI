# LEGACY - COMEX SI first attempt

This directory contains compatibility code and tests from the abandoned COMEX silver-futures / SI experiment. It is retained only for audit history and is not imported by the active XAG/USD Dukascopy spot pipeline.

The active project uses `config.yaml`, `src/data/market_candle_builder.py`, `src/features/market_features.py`, `src/directional_labels.py`, `src/models/multiclass_prediction.py`, and `reports/spot_dukascopy_20261115/`.
