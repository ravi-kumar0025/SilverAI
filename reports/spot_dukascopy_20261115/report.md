## Executive result

The final project uses binary Up/Down labels for XAG/USD spot. The stored artifact and `metrics.json` select `H=12` candles, or 60 minutes on 5-minute data, with `k=0.3`. Stored calibrated walk-forward accuracy is 53.27% mean; stored raw holdout accuracy is 49.03% and calibrated holdout accuracy is 54.61% at the same AUC (0.507). The candidate is therefore not promoted as a reliable trading model.

This is a deliberate evidence-based conclusion. Earlier experiments used a different multiclass/futures contract and are not comparable to this binary XAG/USD spot result.

## Feature contract

The final model uses 34 causal features in five switchable groups: eight silver price/return features, four volatility features, seven trend/momentum features, nine cross-market features, and six UTC session features. A candle stamped `T` is usable only at `T+5 minutes`.

## Label and validation design

`fwd_ret = log(close[t+H] / close[t])`. A row is Up when `fwd_ret > k*ATR_pct`, Down when `fwd_ret < -k*ATR_pct`, and is dropped inside the dead zone. The study compares `H={3,6,12}` and `k={0.2,0.3,0.5}`. Walk-forward folds are chronological and include purge and embargo gaps; the final 20% holdout is touched once.

## Label and leakage checks

For the selected cross-market candidate, the mean shuffled-label accuracy was 54.53% and the mean flip-test accuracy was 46.30%. Because the labels are mildly imbalanced, shuffled-label accuracy is not expected to be exactly 50%; it is a diagnostic, not evidence of skill. The flip test behaves as expected for a directional model.

The per-fold JSON contains always-Up, always-Down, majority-class, and RSI (`RSI<30 => Up`, `RSI>70 => Down`) baselines. It also records class balance and dropped rows for every horizon and threshold.

## Final holdout

| Metric | Raw | Calibrated |
|---|---:|---:|
| Accuracy | 49.03% | 54.61% |
| Balanced accuracy | 50.29% | 51.00% |
| AUC | 0.5070 | 0.5070 |
| Log loss | 0.6995 | 0.6902 |
| Brier score | 0.2531 | 0.2485 |

At confidence thresholds 0.55, 0.60, 0.65 and 0.70, the stored calibrated artifact emitted 1,689, 19, 1 and 0 holdout signals respectively. The .60 subset accuracy was 26.32% and coverage 0.24%; this is not evidence of a reliable selective edge. The stored artifact does not include the actual holdout class rate or always-Up/majority holdout baseline; those values are UNKNOWN and were not recomputed because this holdout is permanently closed.

Calibration changes probabilities and therefore the 0.5 direction decision, while AUC is rank-based and unchanged by a monotonic probability calibration. Consequently calibrated accuracy can differ from raw accuracy at the same AUC; here the stored calibrated probabilities improved log loss/Brier but did not establish predictive reliability.

## Per-fold, cost and what did not work

For the stored H12/k=.3 core-plus-cross candidate, calibrated validation accuracy by fold was 55.23%, 51.30% and 53.29%; corresponding AUC values were 0.5445, 0.5307 and 0.5249. These are stored artifact values, not a new run. The paper-trading code supports cost sensitivity, but no verified trade ledger exists for this reconciled artifact; 1x/2x/3x cost results are therefore UNKNOWN. Configured base assumptions are 2 bps spread and 1 bps slippage, applied by the paper-only evaluator.

What did not work: the stored model did not show a consistent holdout edge; confidence .60 produced only 19 stored holdout signals at 26.32% accuracy, and the original candidate's calibration did not produce dependable selective coverage. Cross-market features did not create a reliable improvement. No profitability claim is made.
