# SilverAI API

The FastAPI app exposes the XAG/USD spot terminal. Start it from the repository root:

```powershell
\.venv\Scripts\python.exe -m uvicorn backend.main:app --host 127.0.0.1 --port 8000
```

`GET /api/market/candles?limit=288` returns complete historical XAG/USD candles sourced from the Dukascopy 1-minute file and resampled in UTC. The response includes `data_status: historical`, `source`, `timezone`, and session statistics. The source has no volume column; volume is unavailable, is not a model feature, and is not returned by the API.

`GET /api/market/status` reports whether the configured market source is historical or genuinely live. In live mode, `GET /api/live/status` reports the helper connection, accepted candles, companion availability, duplicate/gap counters, last closed candle, and freshness. Freshness uses `config.yaml`'s `live_stale_after_seconds` value.

`GET /api/market/insights` returns causal trader context such as trend, volatility regime, session levels, and cross-market availability. It does not create a forecast from future data.

`GET /api/models` reports the final 34-feature order, selected 60-minute horizon, calibration status, and whether the research artifact is promoted. The feature order is also available in `src/features/spot_features.py`.

`POST /api/predict` accepts one closed-candle observation containing the 34 spot features: price/returns, volatility, trend/momentum, gold/EUR cross-market, and UTC session features. It returns binary Up/Down probabilities, calibrated probabilities when available, confidence, and `NO_CLEAR_SIGNAL` when the configured confidence threshold is not met.

`POST /api/predict/confirmed` accepts the same feature object plus `timestamp` and `close`. It is the persistence boundary for a closed candle and never accepts an unfinished candle as finalized.

`GET /api/predictions` returns immutable persisted forecasts. `POST /api/predictions/evaluate` evaluates eligible historical windows, while live cycles automatically evaluate completed future windows. Rows with missing or gapped future candles remain `pending`.

Prediction, journal, paper-trading, and evaluation routes remain available for the backend contract. They must receive features generated by the shared spot feature pipeline, and predictions must be made only after a candle is closed. Missing cross-market data, stale inputs, or confidence below the configured threshold should be displayed as `No signal`.

Environment paths and identity are configured through `.env.example`; the canonical instrument is `XAGUSD_SPOT` / `XAG/USD`, with UTC timestamps, a default 5-minute input resolution, and a selected 60-minute forecast horizon. The backend loads `.env` automatically when present.
